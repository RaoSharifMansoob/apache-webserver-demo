# Apache Web Server Bash Automation Demo

## Objective
This project demonstrates how to install and configure an Apache2 web server using a Bash automation script.

## Web Server Used
Apache2

## Environment
Ubuntu Linux Virtual Machine

## Steps Performed

1. Updated system packages
2. Installed Apache2 web server
3. Started and enabled Apache service
4. Created a custom web page
5. Automated all steps using a bash script

## Script File
apache_setup.sh

## How to Run

Make script executable:
chmod +x apache_setup.sh

Run script:
./apache_setup.sh

## Verification
Open browser and visit:
http://localhost

## Result
Apache web server runs and displays the custom page.
